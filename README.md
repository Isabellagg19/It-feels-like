# It-feels-like
It feels like is an interactive and really fun website where you can explore different pages depending on the mood you’re feeling that day, from nostalgic vibes to being completely focused on studying, and find a playlist made by me specifically for each mood. (If you have any suggestions or songs I should add, I’d love to hear them!) You’ll also find a bunch of pretty cool fun facts that match the vibe of each playlist.

I made it using HTML for the structure, from creating the different pages to organizing every detail, JavaScript to bring it to life, especially the fun facts box, and CSS to give it my own special touch, like the text effects and the unique backgrounds for each page.

This was my first project adding something from Spotify, so I really enjoyed creating the playlists and learning how to integrate them into the website. I truly hope you enjoy it as much as I enjoyed creating it.
